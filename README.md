1. I think the for loop will run as the Update method runs and complete before the Update method finishes. So it would loop frame by frame and we wouldn't have to worry much about the game lagging. 2. When testing the game I found out that the cat can get stuck as it jumps through a platform, leaving him stuck in between the platform blocks. It can happen on the side blocks of the platforms too, so he can just stay floating in midair. My code allows this logic because I wrote an if statement that disables and enables the cat's collider, and the parameter for the if statement is whether the cat is moving upwards on the y axis (_rigidbody.linearVelocityY > 0). So since the cat is still in the "moving upwards" state, the collider will still be disabled and the regular physics of the platform interacting with the cat will not function, causing it to be stuck in the platform instead of landing on it.
